# XDesk 0.6.0 beta 3

[中文说明见下方](#xdesk-060-测试版-3)

A small **beta** on top of beta 2: the phone becomes a game console. It installs over beta 2, beta 1 or 0.5.1, which stays the latest stable release. Everything in [beta 2](https://github.com/n2ray/xdesk/releases/tag/v0.6.0-beta.2) still applies.

## New: game passthrough
Cloud gaming apps such as GeForce NOW run fine on the external screen, and a gamepad has always worked. A keyboard and mouse did not: XDesk sends them on as injected events, and these apps want the real ones.
- Press **Ctrl+Alt+G** with an Android app on the external screen: XDesk lets go of the keyboard and mouse, the app gets the real ones, and XDesk's cursor hides. Mouse look, WASD and every key work as on a PC.
- **Ctrl+Alt+G** again, or **a touch on the phone**, ends it: the keyboard and mouse are XDesk's again.
- **GeForce NOW, Steam Link and Moonlight** go into game passthrough by themselves when they open on the external screen.
- The keyboard and mouse must be connected to the phone (Bluetooth or USB). The picture can still go to a wireless receiver, such as a projector.
- While it is on, the Dock, the notification centre and the other XDesk shortcuts wait until you leave it.

## Changes
- The split screen prototype is no longer in Settings: input did not reach the apps yet and it could not always be closed. The work continues in [#10](https://github.com/n2ray/xdesk/issues/10).

## Upgrading
- Install the APK over beta 2. Run the installer again in Termux for the new `xdesk` command if you have not since beta 2:
  `curl -fsSL https://raw.githubusercontent.com/n2ray/xdesk/xdesk/xdesk/install.sh | bash`
- Receivers and the Mac app are the same as in beta 2.

# XDesk 0.6.0 测试版 3

在测试版 2 上的一个小测试版：手机成了一台游戏主机。可以直接覆盖安装在测试版 2、测试版 1 或 0.5.1 上；0.5.1 仍是最新的正式版。[测试版 2](https://github.com/n2ray/xdesk/releases/tag/v0.6.0-beta.2) 的内容全部保留。

## 新功能：游戏直通
GeForce NOW 这类云游戏在外屏上跑得很好，手柄也一直能用；键盘和鼠标却不行：XDesk 把它们当模拟事件转发，而这些应用要的是真实的键鼠事件。
- 外屏上是安卓应用时按 **Ctrl+Alt+G**：XDesk 放开键鼠，应用直接拿到真实的键鼠，XDesk 的光标藏起来。鼠标转视角、WASD 和所有按键都和在电脑上一样。
- 再按一次 **Ctrl+Alt+G**，或者**碰一下手机**，就退出直通，键鼠回到 XDesk。
- **GeForce NOW、Steam Link、Moonlight** 在外屏上打开时自动进入游戏直通。
- 键鼠要连在手机上（蓝牙或 USB）。画面照样可以无线投到接收端，比如投影机。
- 直通期间，Dock、通知中心和 XDesk 的其他快捷键要等退出直通后才能用。

## 改动
- 设置里拿掉了分屏原型：输入还进不了应用，有时也关不掉。后续在 [#10](https://github.com/n2ray/xdesk/issues/10) 里继续。

## 升级
- APK 覆盖安装在测试版 2 上。测试版 2 之后还没重新运行过安装脚本的话，在 Termux 里运行一次，拿到新的 `xdesk` 命令：
  `curl -fsSL https://raw.githubusercontent.com/n2ray/xdesk/xdesk/xdesk/install.sh | bash`
- 接收端和 Mac App 和测试版 2 相同。
