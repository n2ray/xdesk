# XDesk 0.6.0 beta 5

[中文说明见下方](#xdesk-060-测试版-5)

A **beta** for the Linux side: Termux alone is now enough, the `xdesk` command keeps itself in step with the app, and a program that does not open says why. It installs over beta 4 and the betas before it, or over 0.5.1, which stays the latest stable release. Everything in beta 2 to beta 4 still applies.

**Run the installer again in Termux** after installing the APK. The new app needs the new `xdesk` command; from now on the app offers to update it by itself:
`curl -fsSL https://raw.githubusercontent.com/n2ray/xdesk/xdesk/xdesk/install.sh | XDESK_VERSION=v0.6.0-beta.5 bash`

## New: Termux alone is enough
- No desktop needed. The installer adds a window manager (xfwm4), and the programs you install (`pkg install firefox`, or inside a proot container) open one by one on the display.
- Every proot-distro container is an environment of its own, with or without a desktop.
- Containers and desktops you install later show up in XDesk by themselves; no more `xdesk setup`. A container removed with proot-distro disappears from XDesk too.
- Before X has ever run, XDesk still lists your programs (without icons until the first one opens).
- LXDE, KDE Plasma, Openbox and i3 are found as desktops too.

## New: the command and the app stay in step
- `xdesk version` shows the command's version.
- When the command is older than the app, the Termux tab says so and offers **Update command**.
- `xdesk update` stays on its line: a beta command moves to the newest beta, or to the release that follows it; a stable one only to stable releases. `xdesk update beta` and `xdesk update stable` switch lines.
- The update downloads the release's own install script and checks it against the release's checksums.
- The installer installs the newest stable release by default; `XDESK_VERSION=beta` gives the newest beta. The install line XDesk copies always names the app's own version.

## New: when a program does not open, XDesk says why
Before, XDesk waited 15 seconds and pointed to a log file. Now it says at once:
- the program is not installed (checked before it starts);
- a library is missing (named);
- it crashed (with the signal);
- it cannot reach the display;
- its graphics failed: XDesk then tries once more with software rendering, and tells you when that worked;
- it ran and exited without opening a window (a command-line program, or one that is already open elsewhere).

## New: `xdesk doctor`
One command checks the setup, one line per item, each with the fix:
- the command and loader, and Termux's permission for other apps;
- the packages needed, the window manager, sound, Chinese fonts, the cursor theme;
- every environment: its programs and desktops, hardware GPU or software rendering, and in containers the PulseAudio library sound needs;
- the X server, including one still running the code from before an app update.

## GPU and sound in containers
- A container with the Turnip driver now gets the same hardware rendering setup as Termux.
- Without it, programs use software rendering, and `xdesk doctor` says so.

## Fixed (from a full review of the command)
- A mistyped session name was accepted: `xdesk start` reported success, and `xdesk switch` stopped the running desktop first. Both now refuse an unknown name before doing anything.
- `xdesk stop` could kill an unrelated process when the desktop had exited on its own and Android had given its process number to another program. xdesk now checks that a process is really the one it started.
- Stopping a desktop always waited about 13 seconds: the clean logout never reached the session. It now does.
- `xdesk stop` no longer stops a PulseAudio you started yourself.
- Language and cursor size were fixed on the day of `xdesk setup`; they now follow the phone and the display each time.
- Phones set to `zh-Hans`/`zh-Hant` locales got English menus.
- Two commands at the same time could start two input methods, or write a broken program list that was never repaired.
- A launch request with a missing value could make the command loop forever.
- Session names with spaces, tabs or quotes broke the lists the app reads; new names are now checked.
- `.desktop` files with Windows line endings were ignored.
- Reading the state is about ten times faster with several environments.

## Upgrading
- Install the APK over beta 4, then run the install line above once in Termux.
- Receivers and the Mac app are the same as in beta 2.

# XDesk 0.6.0 测试版 5

Linux 这一侧的测试版：只装 Termux 就能用，`xdesk` 命令和 App 自动对齐，程序打不开时会说明原因。可以直接覆盖安装在测试版 4 及之前的测试版上，也可以装在 0.5.1 上；0.5.1 仍是最新的正式版。测试版 2 到 4 的内容全部保留。

**装好 APK 后，在 Termux 里再运行一次安装命令。**新 App 需要新的 `xdesk` 命令；以后 App 会自己提示更新：
`curl -fsSL https://raw.githubusercontent.com/n2ray/xdesk/xdesk/xdesk/install.sh | XDESK_VERSION=v0.6.0-beta.5 bash`

## 新功能：只装 Termux 就能用
- 不需要桌面。安装脚本会装上窗口管理器（xfwm4），你装的程序（`pkg install firefox`，或者装在 proot 容器里的）可以一个一个单独打开到外屏上。
- 每个 proot-distro 容器都是一个独立的环境，有没有桌面都行。
- 之后再装的容器和桌面，XDesk 会自己发现，不用再运行 `xdesk setup`。用 proot-distro 删掉的容器，XDesk 里也会跟着消失。
- X 还没启动过时，XDesk 也能列出你的程序（先没有图标，打开第一个程序后就有了）。
- 桌面还认 LXDE、KDE Plasma、Openbox 和 i3。

## 新功能：命令和 App 自动对齐
- `xdesk version` 显示命令的版本。
- 命令比 App 旧时，Termux 那一栏会提示，并给出「**更新命令**」。
- `xdesk update` 沿着当前这条线更新：测试版的命令升到最新的测试版，或者升到之后的正式版；正式版的命令只升到正式版。`xdesk update beta`、`xdesk update stable` 换线。
- 更新时下载的是那个版本自己的安装脚本，并用那个版本的校验值核对。
- 安装脚本默认装最新的正式版，`XDESK_VERSION=beta` 装最新的测试版。XDesk 帮你复制的安装命令总是带 App 自己的版本。

## 新功能：程序打不开时，XDesk 会说原因
以前要等 15 秒，然后让你去看日志文件。现在马上告诉你：
- 程序没装好（启动前就会检查）；
- 缺少某个库（给出库名）；
- 程序崩溃了（给出信号）；
- 连不上显示；
- 图形初始化失败：这时 XDesk 会用软件渲染再试一次，成功了也会告诉你；
- 程序运行完就退出了，没有打开窗口（命令行程序，或者已经在别处打开的程序）。

## 新功能：`xdesk doctor`
一条命令检查整套设置，每项一行，并说怎么修：
- 命令和加载器、Termux 是否允许别的应用运行命令；
- 需要的包、窗口管理器、声音、中文字体、光标主题；
- 每个环境：有几个程序和桌面，GPU 是硬件加速还是软件渲染，容器里有没有声音需要的 PulseAudio 库；
- X 服务器，包括还在跑 App 更新前代码的情况。

## 容器里的 GPU 和声音
- 装了 Turnip 驱动的容器，现在和 Termux 一样走硬件加速。
- 没装的用软件渲染，`xdesk doctor` 会说明。

## 修复（来自对命令的一次全面审查）
- 会话名打错了也被接受：`xdesk start` 报成功，`xdesk switch` 还会先停掉正在用的桌面。现在名字不对，什么都不做就直接拒绝。
- 桌面自己退出后，如果 Android 把它的进程号分给了别的程序，`xdesk stop` 可能误杀那个程序。现在会先确认进程真是自己启动的那个。
- 停桌面总要等 13 秒左右：正常注销一直没有送到会话。现在能送到了。
- `xdesk stop` 不再停掉你自己开的 PulseAudio。
- 语言和光标大小以前停在运行 `xdesk setup` 那天的设置，现在每次都跟着手机和屏幕走。
- 语言设成 `zh-Hans`/`zh-Hant` 格式的手机，菜单会变成英文。
- 两个命令同时运行时，可能启动两个输入法，或者写坏程序列表而且不会再修好。
- 启动请求缺一个参数时，命令可能一直空转。
- 会话名带空格、tab 或引号会弄坏 App 读的列表；现在新增时会检查名字。
- Windows 换行格式的 `.desktop` 文件被忽略。
- 环境多的时候，读取状态快了大约十倍。

## 升级
- APK 覆盖安装在测试版 4 上，然后在 Termux 里运行一次上面的安装命令。
- 接收端和 Mac App 和测试版 2 相同。
