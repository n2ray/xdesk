# XDesk 0.6.0 beta 1

[中文说明见下方](#xdesk-060-测试版-1)

This is a **beta** of 0.6.0, a large rework of how XDesk shows things on the external screen and how you move between them. It installs over 0.5.1, which stays the latest stable release. The new parts have had less testing than the rest; see *Known limits*.

## New features

### One switchboard for everything
- The phone's list, the external screen's home (the Launchpad) and the Dock are one model: the same tabs (Running, Favourites, Phone, then one per device), the same items, the same order. Changing the tab or the search on one screen changes it on the other.
- Search covers every device at once, with pinyin initials; the current device's results come first.
- With a mouse attached, the phone stays on the list after something opens (the phone is the switcher, the touchpad is one tap away); without one it goes to the touchpad as before.
- **Item card**: long-press an item on the phone, or right-click it on the external screen, for one card with everything about it: Open / Switch to, Close or Quit, Hide, favourite and its place, and the item's own settings. For the item already on the screen the first button is **Open the Launchpad**.
- **Device badges**: icons of a Mac's or a Linux environment's items carry a small badge at the bottom-left (a display for a Mac, `>_` for Termux, the distro's initial for proot or chroot), in a colour fixed per device. The phone's own apps have none, so the same app on two devices can be told apart.

### The Dock, the same everywhere
- Push the pointer against the bottom edge of the external screen to open the Dock, over any content: Android apps, Linux windows and desktops, a Mac.
- It shows what is on the screen, the previous item, your favourites and **All**; right-click an icon for its card.
- When there are more favourites than fit, the icons shrink first; if they still don't fit, a **+N** tile says how many are left out and opens the Launchpad's favourites.

### Devices, added when you want them
- A first start shows only the phone's own apps. Linux and Macs are added in **Settings › Connect device › Add device**.
- **Linux**: Termux itself and every proot or chroot environment the `xdesk` command knows are devices of their own, with their apps always listed. Opening a Linux program starts a light X (window manager only, no desktop) and shows the program full screen; **Whole desktop** is first in every Linux tab and the only thing that starts the desktop. **Stop** ends the X server.
- Adding Termux asks for its permission and reads what is set up. With no `xdesk` in Termux yet, **Install xdesk in Termux** copies the install line and opens Termux.
- If Termux is uninstalled or installed again, XDesk tells you and forgets what it knew of the old one.

### Keyboard, mouse and input methods
- A physical keyboard and mouse belong to the external screen by default, for every content. **Ctrl+Alt+M** gives them to the phone and back.
- Whoever shows the picture composes the text: a Mac uses its own input method; Linux uses fcitx5 in Termux (if installed), with its candidate window on the external screen at the text. **Shift+Space** switches fcitx5's input method (Android keeps Ctrl+Space for itself).
- The X side's keyboard layout is a setting: the **Keyboard layout (X side)** row on the Linux device page, or `xdesk ime layout NAME` (for example `de`, `fr`, `de-nodeadkeys`).
- Per device: **Keyboard types with the phone's input method**, for when you prefer the phone's.

### Mac (compatible with Sill)
XDesk's Mac support is a client for [Sill](https://github.com/Saffsanity/sill) by Noah Saffer, the open-source app that streams a Mac's windows and desktop to other devices. Install Sill 0.6.1 or later on the Mac (Apple silicon); XDesk pairs with it and speaks its protocol. The client follows [Sall](https://github.com/n2ray/sall), an Android client for Sill, whose code it reuses under the Apache License 2.0. XDesk is not an official Sill app; the Mac's stream settings belong to Sill and change for every device connected to it.
- Mac windows, apps and the whole desktop as contents on the external screen. A locked Mac shows its lock screen and can be unlocked by typing.
- **Pairing** by address and code, by scanning the QR code in Sill's pairing window, by a `sill://pair` link, or with **Ask the Mac for a code**.
- **Picture modes** Sharp / Balanced / Smooth in one tap (Mac device page, the Mac item's card, the picture page); **Ctrl+Alt+Q** cycles them while a Mac is on the screen.
- **Lower quality automatically on a weak link** (on by default): when the link falls behind for 5 seconds XDesk takes the Mac's suggestion, and after 2 calm minutes steps back towards the mode you chose.
- **Picture and sound** page: quality, resolution, frame rate, encoding speed, virtual display, sound, and the **round trip** time with advice when it stays high.
- **Sound** from the Mac, on by default (it needs **Send Audio** on in Sill). **Mute this device**; pulling the headphones the sound plays on mutes it instead of moving it to the loudspeaker.

### Receivers (XDesk Receiver, the web page, the Mac app)
- **Overview** (the Launchpad) and **Switcher** (the next item) on XDesk Receiver's handle and in its gestures; **Back**, **Home** and **Overview** on the web page's toolbar; **Overview** on the Mac app's bar.
- A receiver's pointer opens the Dock over Linux and Mac content too, and works it.
- The Mac app keeps Command and Ctrl apart when you control a Mac.
- The phone's touch settings (natural scrolling, pointer and scroll speed) apply on the receivers.

### Installer and Linux
- On Adreno GPUs the installer adds Turnip, so Linux programs get the real GPU; Mesa falls back to software rendering where Turnip can't run.
- The installer explains `allow-external-apps` and asks before turning it on.
- New `xdesk` commands: `envs`, `apps`, `launch`, `ime` (`status`, `setup`, `start`, `stop`, `on`, `off`, `layout`), and `NAME+apps` sessions.

## Improvements and fixes
- The Launchpad and the Dock keep the same size whatever the Android apps' interface size is; they no longer shrink after an app or a Linux program changed it.
- Mac windows and the Mac cursor are no longer resized by the Android apps' interface size. The setting is now called **Android apps' interface size**; the screen's **Size** sizes everything else.
- The Dock no longer jitters when the pointer crosses the gaps between icons.
- The Launchpad turns a page per mouse-wheel notch (it needed three).
- Mac sound: a buffer that adapts to the network, so Wi-Fi or VPN jitter no longer cuts the sound.
- Ctrl+Alt+M with the Dock open closes it.
- One icon style for an item on every screen.
- "Continue on the phone" appears on the external screen only when something really opens on the phone.
- The X side's input method keeps working when you go from a single Linux program to the whole desktop.
- fcitx5's candidate window shows (it was hidden by Termux's on-screen-keyboard mode).
- Chromium and other programs that draw their own frame fill the screen without a shadow margin.
- The mouse cursor over a Mac window no longer flickers; switching between Mac windows no longer says "another device".
- Fixed: a crash when checking the X server's build, and a crash when disconnecting a Mac.
- A key or button is released where it was pressed, also when the content changed in between.
- An X server from an older XDesk build is detected after an update, with an offer to restart it.

## Known limits
- The receiver paths (XDesk Receiver, the web page, the Mac app) were not retested on real devices for this beta.
- proot and chroot environments have had little testing.
- Mac sound is not synchronised with the picture.
- One content on the external screen at a time. Several windows side by side, Windows PCs and receiver protocol v3 come later.

## Upgrading
- Install the APK over 0.5.1. If the desktop was running during the update, XDesk asks once to restart the X server (programs on it close).
- Run the installer again in Termux to get the new `xdesk` command:
  `curl -fsSL https://raw.githubusercontent.com/n2ray/xdesk/xdesk/xdesk/install.sh | bash`
- If you already used Termux with XDesk, it stays a device; nothing to add.
- On receivers, install the new `xdesk-receiver.apk`, and on a Mac the new `XDesk-macos-arm64.dmg`.

# XDesk 0.6.0 测试版 1

这是 0.6.0 的**测试版**。这一版大幅改造了 XDesk 在外屏上显示内容、在内容之间切换的方式。可以直接覆盖安装在 0.5.1 上；0.5.1 仍然是最新的正式版。新功能测得比原有部分少，见下面的「已知局限」。

## 新功能

### 一个交换台管所有内容
- 手机上的列表、外屏的主页（启动台）和 Dock 用的是同一份内容：同样的页签（正在运行、收藏、手机，然后每个设备一个）、同样的项目、同样的顺序。在一块屏上切换页签或搜索，另一块屏跟着变。
- 搜索一次覆盖所有设备，支持拼音首字母，当前设备的结果排在最前面。
- 接着鼠标时，打开内容后手机停留在列表上（手机当切换器用，触摸板点一下就到）；没接鼠标时照旧进入触摸板。
- **卡片**：在手机上长按某一项，或在外屏上右键点它，弹出一张包含这一项所有操作的卡片：打开 / 切换到、关闭或退出、隐藏、收藏和收藏里的位置，以及这一项自己的设置。正在外屏上的那一项，第一个按钮是**打开启动台**。
- **设备小标记**：Mac 和 Linux 环境里的项目，图标左下角带一个小徽章（Mac 是显示器图形，Termux 是 `>_`，proot 或 chroot 是发行版首字母），每台设备一个固定颜色。手机自己的应用没有徽章，所以两台设备上的同一个应用一眼就能分开。

### Dock：所有内容上用法一样
- 把鼠标推到外屏底边再往下推一点，Dock 就出来了。安卓应用、Linux 窗口和桌面、Mac 上都一样。
- 里面是正在显示的、上一个、你的收藏和**全部**；右键点图标打开它的卡片。
- 收藏太多放不下时，先把图标缩小；还放不下就出现一格 **+N**，说明还有几个没放下，点它打开启动台的收藏页。

### 设备按需添加
- 第一次打开只有手机自己的应用。Linux 和 Mac 在 **设置 › 连接设备 › 添加设备** 里添加。
- **Linux**：Termux 本身，以及 `xdesk` 命令知道的每个 proot 或 chroot 环境，各自是一台设备，应用一直列着。打开一个 Linux 程序会起一个轻量 X（只有窗口管理器，没有桌面），程序全屏显示；每个 Linux 页签第一项是**整个桌面**，只有它会启动完整桌面。**停止**会结束 X 服务器。
- 添加 Termux 时会请求它的权限并读取已有的设置。Termux 里还没有 `xdesk` 时，**在 Termux 里安装 xdesk** 会复制安装命令并打开 Termux。
- Termux 被卸载或重新安装后，XDesk 会提示你，并清掉记下的旧 Termux 的一切。

### 键盘、鼠标和输入法
- 实体键盘和鼠标默认交给外屏，所有内容都一样。**Ctrl+Alt+M** 把它们交给手机，再按一次交回外屏。
- 谁显示画面，就由谁的输入法打字：Mac 用它自己的输入法；Linux 用 Termux 里的 fcitx5（装了的话），候选框出现在外屏的文字旁边。**Shift+空格** 切换 fcitx5 的输入法（Ctrl+空格被安卓自己占用）。
- X 这边的键盘布局成了一个设置：Linux 设备页里的**键盘布局（X 这边）**，或命令 `xdesk ime layout 名称`（例如 `de`、`fr`、`de-nodeadkeys`）。
- 每台设备都有**实体键盘用手机输入法打字**，喜欢用手机输入法时打开。

### Mac（兼容 Sill）
XDesk 的 Mac 支持是 [Sill](https://github.com/Saffsanity/sill) 的客户端。Sill 是 Noah Saffer 开发的开源软件，把 Mac 的窗口和桌面串流到其他设备。Mac（Apple 芯片）上要装 Sill 0.6.1 或更新版本，XDesk 和它配对、使用它的协议。客户端照着 Sill 的安卓客户端 [Sall](https://github.com/n2ray/sall) 实现，按 Apache License 2.0 复用了它的代码。XDesk 不是 Sill 的官方应用；Mac 的串流设置属于 Sill，改了会对连到这台 Mac 的所有设备生效。
- Mac 的窗口、应用和整个桌面都可以作为内容显示在外屏上。Mac 锁屏时显示锁屏界面，直接打字就能解锁。
- **配对**：输入地址和配对码、扫描 Sill 配对窗口里的二维码、打开 `sill://pair` 链接，或点**让 Mac 显示配对码**。
- **画质三档**：清晰 / 平衡 / 流畅一键切换（Mac 设备页、Mac 项目的卡片、画面页里都有）；Mac 在外屏上时按 **Ctrl+Alt+Q** 循环切换。
- **网络变差时自动降低画质**（默认开）：网络连续 5 秒跟不上，就照 Mac 的建议降档；稳定 2 分钟后，逐步回到你选的那一档。
- **画面和声音**页：画质、分辨率、帧率、编码速度、虚拟显示器、声音，以及**网络往返**时间，偏高时会给出建议。
- **Mac 的声音**默认打开（需要在 Sill 里打开 **Send Audio**，XDesk 里对应「Mac 发送声音」）。可以**静音这台设备**；拔掉正在播放的耳机时会自动静音，不会改从外放播出来。

### 接收端（XDesk 接收器、网页端、Mac App）
- XDesk 接收器的把手和手势里有**总览**（启动台）和**切换器**（下一个）；网页端的工具栏有**返回**、**主页**和**总览**；Mac App 的工具栏有**总览**。
- 接收端的鼠标在 Linux 和 Mac 内容上也能叫出 Dock，并操作它。
- 用 Mac App 控制 Mac 时，⌘ 和 Ctrl 分得开。
- 手机上的触控设置（自然滚动、指针速度、滚动速度）在接收端上同样生效。

### 安装脚本和 Linux
- 在 Adreno GPU 的手机上，安装脚本会装上 Turnip，Linux 程序可以用真正的 GPU；Turnip 跑不了的老 GPU 会自动退回软件渲染。
- 安装脚本会先解释 `allow-external-apps` 是什么，问过你才打开。
- `xdesk` 新命令：`envs`、`apps`、`launch`、`ime`（`status`、`setup`、`start`、`stop`、`on`、`off`、`layout`），以及 `名称+apps` 会话。

## 改进和修复
- 启动台和 Dock 的大小不再受安卓应用界面大小影响，不会再在某个应用或 Linux 程序改过之后变小。
- Mac 窗口和 Mac 光标也不再受安卓应用界面大小影响。这个设置改名为**安卓应用界面大小**；屏幕的**大小**一档管其他所有东西。
- 鼠标横着划过 Dock 图标之间的缝隙时，Dock 不再抖动。
- 启动台里鼠标滚轮滚一格翻一页（以前要滚三格）。
- Mac 声音：缓冲会随网络自动调整，Wi-Fi 或 VPN 抖动时声音不再断断续续。
- Dock 打开时按 Ctrl+Alt+M，Dock 会收起。
- 同一项在各个屏幕上的图标一致。
- 只有真的要在手机上操作时，外屏才提示「在手机上继续」。
- 从单个 Linux 程序切到整个桌面后，X 这边的输入法照常可用。
- fcitx5 的候选框能显示出来了（之前被 Termux 的屏幕键盘模式藏起来了）。
- Chromium 等自己画边框的程序全屏时铺满屏幕，不再留阴影边。
- Mac 窗口上的鼠标光标不再闪烁；在 Mac 的窗口之间切换时，不再误报「另一台设备」。
- 修复：检查 X 服务器版本时闪退；断开 Mac 时闪退。
- 按键和鼠标按钮总在按下的地方松开，中途换了内容也一样。
- 更新后能认出旧版本 XDesk 起的 X 服务器，并提示重启它。

## 已知局限
- 接收端（XDesk 接收器、网页端、Mac App）这一版没有在真机上重新测试。
- proot 和 chroot 环境测得很少。
- Mac 的声音和画面不同步。
- 外屏一次只显示一个内容。多个窗口并排、Windows 电脑、接收端协议第 3 版留到以后。

## 升级
- 直接把 APK 覆盖安装在 0.5.1 上。如果更新时桌面在运行，XDesk 会提示重启一次 X 服务器（上面的程序会关掉）。
- 在 Termux 里再运行一次安装脚本，拿到新版 `xdesk` 命令：
  `curl -fsSL https://raw.githubusercontent.com/n2ray/xdesk/xdesk/xdesk/install.sh | bash`
- 以前就在 XDesk 里用 Termux 的，它仍是一台设备，不用重新添加。
- 接收端请装新的 `xdesk-receiver.apk`，Mac 上装新的 `XDesk-macos-arm64.dmg`。
