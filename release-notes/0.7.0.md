# XDesk 0.7.0

[中文说明见下方](#xdesk-070-1)

The redesign: every screen of XDesk was drawn again as one design, and the app now follows it. The phone gets a second interface, dimming you can control, and one list of every permission XDesk uses. It installs over 0.6.6 and over the 0.7.0 betas.

**Update the receivers too**: XDesk Receiver (`xdesk-receiver.apk`) on a tablet or projector, and the Mac app (`XDesk-macos-arm64.dmg`), have the new look and should be the same version as the phone. The `xdesk` command in Termux: run `xdesk update` for the X server fixes below.

## The phone
- **Two phone interfaces** (Settings › General › Phone interface): **Console**, the touchpad first, as before; or **Launchpad**, an app grid as the phone's home in portrait and landscape. Tap an icon and it opens on the big screen while the phone stays on the grid; the touchpad is one tap away. Both offer the same functions.
- The phone and the big screen each remember their own tab and search.
- **Dimming**: a moon button dims the phone at once. Settings › General › Dim automatically: off, 30 s, 1, 5 or 10 minutes. It only dims while a screen is connected (a cable, a receiver, a browser or the Mac), also when nothing is open there; without one it never dims by itself. The first touch on a dimmed phone only brings the light back, it does not press anything.
- The function keys open above the touchpad, so the thumbs don't hit them; the full-screen touchpad has the same corners in portrait and landscape.
- On/off buttons (keyboard and mouse on the big screen, Ctrl, favourites) show their state by look, never by "on/off" words.

## Permissions, all in one place
- **Settings › Permissions** lists what XDesk can ask for: required (wireless debugging or Shizuku, display over other apps), recommended (notifications), and the ones only some features need. Each has a page saying what it is for, what happens without it, and how to turn it on.
- **Before you start**: a first-start checklist on a new install (an update never shows it).
- A required permission that was on and got lost (after a reboot, or revoked) shows a bar in the app, one notification, and a red dot on Settings. Settings that need a missing permission say so where they are.
- Full disclosure, also on the website: no root, no accessibility, no storage, phone, location or contacts.

## Everything else looks new
Settings, the item card, the external screen's home, Launchpad, Dock, notifications, sidebar and Mac menu, the privacy cover, the car screen, activation and Shizuku pages, the gamepad and its editor, XDesk Receiver, the web display and the Mac app. Receivers use the mirrored logo (mirrored means receive), the Mac app's icon included.

## Fixed
- The X server no longer crashes when a desktop stops (a NULL read in glamor at close), and `xdesk.log` now says how X ended (exit status or signal).
- The Mac menu on the phone (long-press a Mac › Menu) could not open.

## Since the betas
- The Mac menu on the external screen is one piece with its button: the same height, no app name on hover or in the bar, the dropdown square on top and round below.
- The Mac app while waiting for the phone shows the logo, and "allow USB debugging on the phone" and the Accessibility reminder as cards under how to connect.
- Connect to a receiver: the network search stops after 15 seconds; none found says so, with **Search again**.
- No external screen: the hint above the list and the Launchpad grid is a card, not a line of orange text.
- The phone list's search field no longer cuts its hint at half the box; narrow ones use a shorter hint.
- Settings › Permissions reads autostart on MIUI and HyperOS correctly.

## New README and website
A short README (what it does, how to use it, the permissions, credits) with the long one kept as MANUAL.md, and a new website drawn in HTML and CSS.

# XDesk 0.7.0

这是**重新设计**的版本：XDesk 的所有界面按同一套设计重画了一遍，App 现在照着它来。手机端多了一种界面，调暗可以自己控制，XDesk 用到的权限都列在一个地方。可直接覆盖安装 0.6.6 和 0.7.0 测试版。

**接收端也请一起更新**：平板或投影上的 XDesk 接收器（`xdesk-receiver.apk`）和 Mac 版（`XDesk-macos-arm64.dmg`）换了新样子，版本要和手机一致。Termux 里运行 `xdesk update`，带上下面 X 服务器的修复。

## 手机这边
- **两种手机端界面**（设置 › 通用 › 手机端界面）：**操作台**，和以前一样触摸板为首页；**启动台**，手机首页是应用网格，横竖屏各一套。点图标就在大屏上打开，手机留在网格上，触摸板一点就到。两种功能一样。
- 手机和大屏各记各的标签和搜索。
- **调暗**：点月亮按钮马上调暗。设置 › 通用 › 自动调暗：关、30 秒、1、5、10 分钟。只在接着屏幕（有线、接收器、浏览器或 Mac）时自动调暗，大屏上什么都没开也算；没接屏幕时不会自己调暗。调暗后第一下触摸只恢复亮度，不会点到任何东西。
- 功能键在触摸板上方展开，拇指不会误碰；全屏触摸板的角按钮横竖屏一致。
- 开关类按钮（键鼠在外屏、Ctrl、收藏）用样式表示状态，不写「开/关」。

## 权限都在一处
- **设置 › 权限**列出 XDesk 可能要的权限：必需（无线调试或 Shizuku、显示在其他应用上层）、推荐（通知），以及只有部分功能才用到的。每项都有说明页：用来做什么、不开会怎样、怎么开。
- **开始之前**：新安装第一次打开时的清单（升级不会弹）。
- 原来开着的必需权限丢了（重启后、或被撤销），App 里会出提示条、发一条通知、设置按钮上有红点。需要某项权限的设置会在原地写明。
- 坦白从宽，网站上也写了：不要 root、不要无障碍、不要存储、电话、位置、通讯录。

## 其他都换了新样子
设置、长按卡片、外屏主页、启动台、Dock、通知、侧边栏和 Mac 菜单、隐私遮罩、车机屏、激活和 Shizuku 页、手柄和手柄编辑、XDesk 接收器、网页显示、Mac 版。接收端都用镜像标志（镜像表示接收），Mac 版的图标也换了。

## 修复
- 停止桌面时 X 服务器不再崩溃（glamor 收尾时读到空指针），`xdesk.log` 会记下 X 怎么结束的（退出码或信号）。
- 手机上的 Mac 菜单（长按 Mac › 菜单）打不开。

## 测试版之后的改动
- 外屏的 Mac 菜单和按钮连成一体：一样高，鼠标指上去和菜单栏里都不再显示应用名，下拉菜单上面直角、下面圆角。
- Mac 版等待手机时显示标志，「在手机上点允许 USB 调试」和辅助功能的提醒以卡片显示在怎么连的下面。
- 连接接收器：在局域网里找 15 秒就停，没找到会写明，并给一个「再找一次」。
- 没有外接屏时，列表和启动台上方的提示是一张卡片，不再是一行橙字。
- 手机列表的搜索框提示不再在框的一半被截断，窄的搜索框用短一点的提示。
- 设置 › 权限能正确读出 MIUI、HyperOS 上的自启动。

## 新 README 和网站
README 改短（能干什么、怎么用、权限、声明和感谢），原来的长文留作 MANUAL.md；网站全部用 HTML 和 CSS 重画。
