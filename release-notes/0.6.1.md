# XDesk 0.6.1

[中文说明见下方](#xdesk-061-1)

A fix release for XDesk Receiver on a touch tablet. It installs over 0.6.0.

## Fixed: fingers on XDesk Receiver reached no app
- In 0.6.0, with an Android app set to **Like a tablet** (a game, GeForce NOW), touching the picture on XDesk Receiver did nothing at all: the phone received every finger but dropped them before the app. They now reach the app, all of them, so games that need several fingers work as the 0.6.0 notes said.

## Changed: one Like a computer / Like a tablet for the phone and the receiver
- The mode is one choice per app, kept on the phone. Switching it in XDesk Receiver's handle now switches it on the phone too, and the other way round; before, the handle changed only the receiver and was forgotten with the next app.
- The handle's button shows the mode now, as the phone's button does. Before, it showed the mode a tap would switch to, so the two sides seemed to disagree.
- An app that keeps its own mouse (RustDesk) can not be switched on the phone; there the handle switches only the receiver, as before.

## Upgrading
- Install the APK over 0.6.0. Update XDesk Receiver (`xdesk-receiver.apk`) on the tablet too: the fingers fix is on the phone, the shared mode needs both.
- An older receiver still works with 0.6.1, with its handle switching only itself; a 0.6.1 receiver with an older phone does the same.
- The protocol gains TOUCH_MODE (35) and FEATURES bit 6 (PROTOCOL.md).
- The Mac app and the `xdesk` command are unchanged apart from the version number.

# XDesk 0.6.1

触屏平板上 XDesk Receiver 的修复版，覆盖安装在 0.6.0 上即可。

## 修复：XDesk Receiver 上的手指传不到应用
- 0.6.0 里，安卓应用设成「像平板」（游戏、GeForce NOW）时，在 XDesk Receiver 的画面上触摸完全没反应：手机收到了每根手指，却在交给应用之前丢掉了。现在所有手指都能传给应用，需要多指的游戏可以玩了，也就是 0.6.0 说明里写的效果。

## 改动：手机和接收端共用一个「像电脑 / 像平板」
- 这个模式是每个应用一个选择，记在手机上。现在在 XDesk Receiver 的把手里切换，手机上也跟着变，反过来也一样。以前把手只改接收端自己，换个应用就忘了。
- 把手里的按钮现在显示当前模式，和手机上的按钮一样。以前它显示的是「点了会切成什么」，看起来两边总不一致。
- 自带鼠标方式的应用（RustDesk）在手机上不能切换，这时把手和以前一样只切换接收端自己。

## 升级
- APK 覆盖安装在 0.6.0 上。平板上的 XDesk Receiver（`xdesk-receiver.apk`）也要更新：手指的修复在手机端，共用模式要两边都是新版。
- 旧的接收端连 0.6.1 照样能用，把手只切换它自己；新接收端连旧手机也一样。
- 协议加了 TOUCH_MODE（35）和 FEATURES 第 6 位（见 PROTOCOL.md）。
- Mac 版和 `xdesk` 命令除了版本号没有变化。
