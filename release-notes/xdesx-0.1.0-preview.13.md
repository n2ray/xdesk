## Mac 登录与桌面图标

- 外屏 Mac 密码框打开期间，X 桌面释放实体键盘。连接实体键盘时，密码框默认收起软键盘。密码仍由受截图保护的 Android 窗口接收；窗口根据鼠标事件的位置绘制光标。
- 顶栏输入法按钮改用与 Wi-Fi、日历一致的单色线条图标。悬停可查看当前输入法。开始菜单、Mac 设备卡片及共享窗口使用同一个 iMac 样式图标。

## 中文输入

在小米、HDMI、罗技 K380s 和小企鹅输入法（Fcitx5 for Android）的组合上，preview.12 已验证以下方式：

- **有实体键盘**：打开小企鹅设置 → 候选窗口 → 显示候选窗口，选「系统默认」。在外屏安卓 Chrome 中用鼠标点击地址栏，完整软键盘保持收起，键入拼音可显示中文候选。
- **用手机打字**：从「桌面控制 → 手机键盘」启用，再点击外屏安卓应用的输入框。在手机上选词，文字会进入外屏输入框。
- **Ubuntu 应用**：Chrome 地址栏和网页输入框能跟随文字光标。xfce4-terminal 首次冷开仍可能需要重新打开一次。Blender 未上报精确位置时，用实体鼠标点击输入框后，候选框可定位到点击处。

「系统默认」也是小企鹅在手机上的设置，由用户自行选择。xdesx 不会自动修改它。其他输入法及机型的候选框行为仍需实测。
