## 共享桌面

开始菜单 → Mac → **共享桌面** 打开独立设备列表。点击「添加 Mac」保存地址和账户，双击卡片连接，也可选中卡片后按 Enter。「设备设置」可编辑、移除设备和调整该设备的共享分辨率。

每台 Mac 单独打开一扇窗口，重复打开同一卡片会切回已有窗口。关闭列表可以继续使用已打开的共享窗口。每个连接计入桌面窗口上限。密码仍在受保护的 Android 窗口中输入。音视频按远端地址分流，每台 Mac 使用独立的解码器和输入会话。

在 Mac 的「系统设置 → 通用 → 共享」开启屏幕共享并允许账户访问。高性能模式要求 Apple 芯片、macOS Sonoma 14 或更新版本、稳定的低延迟网络。每台 Mac 同时接受一个高性能会话。[Apple 屏幕共享要求](https://support.apple.com/guide/mac-help/mchl1883115d/mac)
