Your phoneon any screen 手机里的应用搬上大屏

Install one app, activate it once, connect a screen. Your Android apps run full screen, and the phone becomes the touchpad and keyboard. 装个 App，激活一次，插上显示器。应用在大屏上全屏运行，手机拿来当触摸板和键盘。

Get started开始使用 Source on GitHub查看源码

Three steps to a big screen三步用起来

Android 11 or newer. No root, no computer, nothing else to install. 安卓 11 及以上就行。不用 root，不用电脑，也不用装别的。

1

Install the app安装 App

Download xdesk.apk from the latest release and install it. 到发布页下载 xdesk.apk，装上就行。

If your file manager refuses, use adb install -r xdesk.apk. 文件管理器装不了的话，用 adb install -r xdesk.apk。

2

Activate it once激活一次

On Wi-Fi, turn on Wireless debugging and type the pairing code into XDesk. Then allow its overlay permission. 连上 Wi-Fi，打开无线调试，把配对码输进 XDesk，再给它悬浮窗权限。

On Xiaomi, also turn on USB debugging (Security settings). Shizuku works too. A reboot needs activation again. 小米手机还要打开“USB 调试（安全设置）”。已经在用 Shizuku 的话，直接用它也行。手机重启后要重新激活。

3

Connect a screen接上屏幕

Plug in a monitor over USB-C, open XDesk and tap an app. 用 USB-C 线连上显示器，打开 XDesk，点一个应用。

If plugging in a monitor mirrors your screen, your phone qualifies. No cable? Keep scrolling. 插上显示器能镜像手机画面，就说明支持。没有线也没关系，往下看。

Not just monitorsHere is what else it can do不只能接显示器还能这样用

Android apps in full screen安卓应用全屏运行

The apps already on your phone, on the display. A Bluetooth mouse and keyboard work too. 手机里现成的应用，直接放到大屏上用，也能接蓝牙鼠标和键盘。 Needs USB-C video output 手机要支持 USB-C 视频输出

Linux desktopsLinux 桌面

XFCE and more from Termux, proot or chroot, with GPU acceleration in Termux on Adreno. Termux、proot、chroot 里的 XFCE 等桌面都能跑，骁龙手机上的 Termux 还有 GPU 加速。 Optional. Needs Termux 可选，要装 Termux

Another Android device另一台安卓设备

No cable? Cast over Wi-Fi to XDesk Receiver on a projector, TV box or old phone, picture and sound. 没有线的话，用 Wi-Fi 投到投影、电视盒子或旧手机上，画面声音都有。对方装个 XDesk 接收器就行。 Receiver runs on Android 5.0 or later 接收器要求安卓 5.0 及以上

Any browser用浏览器当显示器

An iPad, laptop or smart TV, with nothing to install on it. Turn on Web display in the settings. iPad、电脑、智能电视，有浏览器就行，什么都不用装。在设置里打开“网页显示”。 For networks you trust 只在信得过的网络里用

In the car车机

Through Android Auto, with sound in the car. Experimental. 通过 Android Auto 投到车机，声音也从车里出。目前还是实验功能。 Parked only 只能停车时用

The phone stays in charge所有操作都在手机上

Touchpad and keyboard触摸板和键盘

Move, tap, drag and scroll. On Linux desktops the phone's input method can type Chinese and other languages. 移动、点按、拖动、滚动都在手机上完成。在 Linux 桌面里，可以直接用手机输入法打中文。

Launcher and dock切换应用

Search your apps and pin favourites. One tap switches what's on the display. 搜索应用，把常用的固定下来，点一下就能换掉大屏上的内容。

One sound setting声音想从哪儿出就从哪儿出

Speaker, Bluetooth, the display or the car. The same setting works for every kind of screen. 手机扬声器、蓝牙耳机、显示器还是车机，在一个地方选，所有屏幕通用。

Add a Linux desktop还想要 Linux 桌面

Optional. Install Termux and run this in it. Your desktops then appear in XDesk's launcher. 装好 Termux，运行下面这行命令，桌面就会出现在 XDesk 的启动器里。

curl -fsSL https://raw.githubusercontent.com/n2ray/xdesk/xdesk/xdesk/install.sh | bash

No desktop yet? pkg install xfce4 xfce4-terminal && xdesk setup. Please read the script first. The README covers everything else. 还没装桌面的话，运行 pkg install xfce4 xfce4-terminal && xdesk setup。运行前建议先看看脚本，更多说明见 README。

Where it stands用之前先了解一下

Tested on very few devices目前只在很少的设备上测过

It is used daily on one phone, the European Xiaomi 15 Ultra. Reports from other devices are very welcome. 平时只在欧版小米 15 Ultra 上用。别的手机不一定一样，欢迎告诉我们结果。

Wireless and web are not encrypted无线和网页模式没有加密

Use them only on networks you trust. 只在信得过的网络里用。

Park before using it in a car在车上要先停车

Never while driving. 开车时不要用。

Android apps need a shell service安卓应用要靠一个 shell 权限的服务

It injects input, which Android doesn't allow normal apps to do, and only XDesk can call it. 安卓不让普通应用给别的应用发送键鼠操作，所以需要它。只有 XDesk 能调用这个服务。

Built by a person and an AI一个人和一个 AI一起做的

XDesk is a project by n2ray and Claude, an AI. n2ray decides what XDesk should do and tests it on real phones, monitors, projectors and cars. Claude wrote most of the code and documentation, including this page.

XDesk 是 n2ray 和 AI Claude 一起做的。n2ray 决定做什么，并在真实的手机、显示器、投影和车机上测试。大部分代码和文档是 Claude 写的，这个页面也是。
