Full disclosure坦白从宽

What it asks for before you install so nothing jumps out at you later要哪些权限 装之前先说清楚 免得装完吓一跳

⌁
Wireless debugging (or Shizuku)无线调试（或 Shizuku）Required必需

Sends keyboard, mouse and touch into Android apps on the big screen.把键鼠和触摸送进大屏上的安卓应用。

Without it: Android apps on the big screen are look-only.不给：安卓应用在大屏上只能看不能动。

▣
Display over other apps显示在其他应用上层Required必需

Draws the cursor and the Launchpad on the big screen.在大屏上画光标和启动台。

Without it: no pointer on the big screen, so barely usable.不给：大屏上没有光标，基本没法用。

◔
Notifications通知Recommended推荐

Type the pairing code right in a notification, and see when the service is running.配对码直接在通知里输，服务在跑也看得见。

Without it: type it inside the app.不给：得进 App 里输。

✉
Notification access通知使用权Turn on when needed用到再开

Brings phone notifications to the big screen.把手机通知搬到大屏上。

Without it: notifications stay on the phone.不给：通知只在手机上响。

>_
Run Termux commands运行 Termux 命令Turn on when needed用到再开

Starts the Linux desktop with one tap.一键开 Linux 桌面。

Not using Linux? Ignore this.不用 Linux 就不用管。

⌗
Camera相机Turn on when needed用到再开

Scan a QR code to add your Mac.扫码加 Mac。

Without it: type the address by hand.不给：手输地址也行。

☾
Do Not Disturb勿扰Turn on when needed用到再开

The Do Not Disturb switch on the big screen.大屏上的勿扰开关。

Without it: the switch does nothing; everything else works.不给：开关点不了，别的照常。

↻
Autostart (Xiaomi etc.)自启动（小米等）Turn on when needed用到再开

Stops the system quietly killing notification forwarding.别让系统把通知转发偷偷掐掉。

Without it: notifications on the big screen come and go.不给：大屏上的通知时有时无。

Not asked for:没要的： Rootroot Accessibility无障碍 Storage存储 Phone电话 Location位置 Contacts通讯录

The honest part: after wireless-debugging pairing, XDesk's service has the same privileges as adb (it can operate the phone, but cannot touch other apps' data); only XDesk can call it, and it stops on reboot. The code still carries an accessibility service inherited from Termux:X11; it is off by default and XDesk will not ask you to turn it on. The wireless receiver, the web display and the Mac Wi-Fi connection are not encrypted; use them on your own network. 说实话的部分：无线调试配对后，XDesk 的服务权限和 adb 一样大（能操作手机，但碰不到别的应用的数据），只有 XDesk 自己能调用它，重启就停。代码里还留着 Termux:X11 带过来的一个无障碍服务，默认关着，XDesk 不会让你开。无线接收器、网页显示和 Mac 的 Wi-Fi 连接都不加密，自家网络用。
